🏠 Real Estate Listing Portal

A modern and responsive Real Estate Listing Portal that allows users to browse properties and find suitable homes or properties using search and filtering options.

📌 Project Overview

The Real Estate Listing Portal is a frontend-based web application designed to provide a simple and user-friendly platform for exploring real estate properties.

Users can browse featured properties, search for properties based on different criteria, apply filters, save favorite properties, and contact agents for further enquiries.

The application is designed without mandatory user authentication, making it simple and easy to access.

✨ Features

- 🏠 Modern and responsive home page
- 🔍 Property search functionality
- 📍 Location-based filtering
- 🏘️ Property type filtering
- 💰 Price filtering
- 🛏️ Bedroom filtering
- ⭐ Featured properties section
- ❤️ Favorite properties
- 📄 Property information and details
- 📞 Contact Agent / Enquiry form
- ℹ️ About Us section
- 📬 Contact Us section
- 📱 Responsive design for different screen sizes
- 🔐 No mandatory login or registration

🔎 Search & Filter

Users can easily find properties using multiple filtering options such as:

- Location
- Property Type
- Price Range
- Number of Bedrooms

The Apply Filters option displays matching properties, while Clear Filters resets the selected criteria.

🏡 Property Listings

The portal displays property listings with important information such as:

- Property name
- Location
- Price
- Property type
- Bedrooms
- Property images

This helps users quickly compare and explore available properties.

❤️ Favorites

Users can mark properties as favorites for easier access and reference while browsing the portal.

📞 Contact Agent

Users can submit an enquiry through the Contact Agent form to request additional information about a selected property.

🛠️ Technologies Used

- JavaScript – Search, filtering and interactive functionality
- GitHub Pages – Project deployment
